# 外部BGM

音楽ファイルは各自で用意してください。音楽なしでも従来どおり遊べます。
設定メニューの「BGM設定...」でXMLを選択すると読み込み、現在の場面に合った曲を再生します。
BGMのオン／オフと音量を調整できます。既存の「サウンド」は効果音のオン／オフです。
効果音の音量は同じ設定画面の別のスライダーで調整します。
設定内容と音量は次回起動時にも引き継ぎます。XMLの編集後は「再読み込み」を押してください。

初回から設定を指定する場合:

```sh
java -Dmicropolis.music=/path/to/music.xml -jar target/micropolis-2.0.0.jar
```

例は [examples/music.xml](../examples/music.xml) を参照してください。
相対パスはXMLファイルのフォルダを基点とします。日本語のファイル名も利用できます。
個人用の音楽パックはGit管理外の `private/music/` などに配置してください。

## 設定

- `music.volume`: パック全体の基準音量（0〜1）。設定画面の音量をさらに掛けます。
- `fadeMillis`: 曲を切り替える際のフェード時間（0〜10000ミリ秒）。順番にフェードアウト／インします。
- `pauseWithGame`: `true` ならシミュレーションの一時停止中にBGMも一時停止します。既定は `false`。
- `track`: 一意の `id` と `file`。`loop` は既定で `true`。
- `track.seconds`: 1回の再生を区切る秒数。0または省略ならファイル終端まで。途中からのループは未対応です。
- `rule.scene`: `title`（新規都市選択中）、`city`（都市プレイ中）、`disaster`（短時間の割り込み曲）。
- `rule.cityClass`: 都市ルールだけに指定できます。0〜5が村・町・都市・首都・大都市・巨大都市。省略なら全段階。
- `rule.priority`: 同じ場面のルールで数値が大きいものを優先。同じ値なら都市クラス指定ありを優先し、それも同じなら先に記述したルール。
- `rule.seconds`: 災害曲への割り込み時間。既定15秒（0.1〜3600秒）。通常曲より優先度が低ければ割り込みません。

災害曲は実際の災害の存続時間と連動しません。指定時間後に現在の都市クラスの曲へ戻ります。
割り込み中の追加通知では曲を頭から再生せず、時間も延長しません。
都市評価の更新時と都市の読み込み時に選曲し直します。同じ曲なら再生位置を維持します。
ゲーム速度を変えても再生速度は変わりません。

## 形式と配布構成

対応目標はPCM WAV、MP3、Ogg Vorbis、FLACです。Ogg Opusや多チャンネル音声は対象外です。
一般音声は8〜192 kHz、モノラル／ステレオを扱います。
Oggは単一論理ストリームに対応し、連結されたOggは対象外です。
SPCは後続の実装で追加予定です。現段階ではSPC対応と表記しません。

JARの隣の `lib/` にデコーダーのJARが必要です。Mavenの `package` で `target/lib/` に配置します。
配布時にJARだけを移動せず、`lib/` とライセンス文書も一緒に置いてください。
ライブラリは個別JARのまま保持し、置き換えて利用できます。

## エラーと検証

設定なしの場合は無音です。設定や音楽が壊れている場合もゲームは継続し、BGM設定画面に理由を表示します。
DTD・外部実体参照・未知の設定項目は受け付けません。XMLから外部コマンドを実行しません。
再生・復号・ファイル読み込みはUIスレッドから分離し、音声全体をメモリに展開しません。

自動テストでは自作の440 Hz正弦波を4形式に変換した素材で復号結果が無音でないことを確認します。
XMLの異常、相対パス、ルールの競合、同じ曲の維持、割り込みからの復帰、一時停止、音量も検証します。

2026-11-02、Windows / Java 25で4形式の音声デバイス出力、ループ、フェード、
一時停止／再開、終了後の再生スレッド解放を確認しました。
音楽未設定での新規都市開始と、日本語のBGM設定画面の表示も確認しています。
音声は生成した正弦波による動作確認であり、楽曲ごとの音質を保証するものではありません。

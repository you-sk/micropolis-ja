# 日本語UIの実機確認

確認日: 2026-11-01

## 環境と対象

- Windows、Eclipse Adoptium Java 25.0.4.1。
- `9e7b553` のソースから作成した `micropolis-2.0.0.jar`。
- `-Duser.language=ja -Duser.country=JP` で起動。
- 確認時のメインウィンドウ画像は1150 × 713ピクセル。OSの表示倍率は変更していません。
- 新規の確認用都市を使用し、既存の利用者データは編集していません。

この確認で変更したのは、実機確認の記録と日本語化の現状の文書です。
確認用の保存データはGit管理外の `private/` に置き、公開ソースには含めていません。
GitHubのフォーク作成・push・リリースは実行していません。

## 検証の限界

- ウィンドウ縮小も試しましたがサイズ変更を確認できず、小さい任意サイズでの表示は未検証です。
- 異なるOS、表示倍率、日本語フォント、複数モニター環境は未検証です。
- 全通知、全施設、全メニュー操作、キーボードのニーモニックは網羅していません。
- 大都市・長時間プレイ時の動作、音声品質、全画像内文字は今回の確認対象外です。
- 既存の27件の自動テストはこの版の直前のクリーンビルドで成功しています。
  今回は実機確認と文書変更のみのため、自動テストを再実行していません。

最初のサンドボックス内起動では、Java Preferencesの設定保存用レジストリへのアクセスが拒否されました。
通常の実行環境で起動し直すと動作しました。これを一般利用環境のゲームの不具合とは扱っていません。
